# Speisekarte

Hier die Speisekarte ablegen, in einem der folgenden Formate:
- `speisekarte.pdf` (einfachste Variante)
- oder als Fotos/Scans (`speisekarte-1.jpg`, `speisekarte-2.jpg`, ...)
- oder als Textdatei/Word-Dokument mit Gerichten, Beschreibungen und Preisen

Falls vorhanden, bitte auch Angaben zu:
- Kategorien (z.B. Vorspeisen, Hauptgerichte, Desserts, Getränke)
- Preisen
- Allergenen/Zusatzstoffen (falls ausgewiesen)

Die Inhalte werden später direkt in die Website übernommen, das PDF/die Fotos dienen nur als Quelle.

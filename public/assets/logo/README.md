# Logo

Hier das Restaurant-Logo ablegen.

Am besten:
- `logo.svg` (bevorzugt, verlustfrei skalierbar)
- zusätzlich `logo.png` (mit transparentem Hintergrund, min. 512×512px) als Fallback
- optional: `favicon.png` (quadratisch, z.B. 512×512px) für den Browser-Tab

Falls vorhanden, gerne auch eine helle und eine dunkle Variante (für helle/dunkle Hintergründe).
